# Chat Interface

Resona's primary conversational surface in the Data Explorer. Ask a question in plain English, and it autonomously inspects your schema, writes optimized SQL, executes read-only queries through your local connector, and answers with interactive results or downloadable deliverables.

![Resona AI main chat interface in Data Explorer with active connection context, chat history, table shortcuts, prompt bar, and voice button](/images/de/resona-ai/de/de.png)

> Quick links: [Data Explorer Overview](/data-explorer) · [Resona Voice](/resona-ai/voice) · [Dashboard AI](/resona-ai/dashboard) · [Workspace & Projects](/resona-ai/workspace)

## 1 — Workspace & Interface Overview

The Resona AI surface is purpose-built for fast data exploration:

- **Sidebar & History**:
  - **`+ New chat`**: Start a fresh conversation with a clean slate anytime.
  - **Projects & Artifacts**: Group sessions into shared workspaces and access all previously generated files.
  - **`YOUR CHATS`**: Full session history with relative timestamps (`5d ago`, `7d ago`) for instant resumption.
  - **Bottom Switcher**: Jump seamlessly between **Explorer** (table grid) and **Dashboard** without losing conversation context.
- **Context Header**:
  - Live breadcrumb tracking the active connection, schema, and table (e.g., `cloopdb > public > admin_chat`).
  - Top-right **Export** button for rapid data exports.
- **One-Click Table Chips**:
  - Pre-populated starter chips (such as `@admin_chat overview`, `@ai_token_logs overview`) let you trigger comprehensive table profiling with a single click.
- **Unified Input Bar**:
  - **`+` Attach files**: Upload external reference spreadsheets, PDFs, SQL scripts, code, or images.
  - **`@` Table mentions**: Autocomplete table names to pre-load schema context.
  - **Folder icon**: Link files directly from existing projects or artifacts.
  - **Mode toggle**: Switch between **Flash** and **Deep** analytical engines.
  - **Voice waveform icon**: Launch [Resona Voice](/resona-ai/voice) instantly right from the input bar.

## 2 — Choose Flash or Deep

**Flash** works fast and gives you the answer directly.
**Deep** does the same work with more time on it — thinking longer and following the question across tables and wider schema instead of stopping at the first answer.

You can switch at any point; it applies from your next message.

---

## 3 — Ask Your Question

Type it however you'd ask a colleague:

> *"Show me the top 10 customers by revenue this quarter"*  
> *"What's the 30-day retention for users who signed up in Q1 vs Q2?"*  

- **Mention a table with `@`** to save Resona a step — pick from the list and it starts with that table already in context.
- **Attach files or images (`+`)** to ask about something that isn't in the database — a spreadsheet, a document, a screenshot, or a code file. Resona reads images directly and answers from what it sees.

---

## 4 — Autonomous SQL Generation

One tool runs SQL, and Resona does all the analysis in that SQL itself — so the approach fits your question instead of being fixed in advance.

- **Read-only safety**: Queries run against a single database, with your schema already loaded, so it usually knows your tables and columns without going looking.
- **Goal-oriented planning**: You give it one question, not a checklist. Resona plans the work, runs the queries it needs, and reports back — asking you only when the request is genuinely ambiguous, and then as a card you can pick from.
- **Self-correcting error recovery**: When a query fails, it reads the error, works out whether it guessed a name wrong or wrote bad SQL, and changes something before retrying. It never repeats a failing query unchanged.

---

## 5 — Reports and Deliverables

Ask for a report and Resona gathers the data first, then writes the document itself — real numbers, real tables, no template.

| | Format | Best for |
|---|---|---|
| ![CSV](/images/data-explorer/formats/csv.svg) | **CSV** | The raw result set |
| ![Excel](/images/data-explorer/formats/excel.svg) | **Excel** | A formatted workbook |
| ![PDF](/images/data-explorer/formats/pdf.svg) | **PDF** | Paginated for printing |
| ![HTML](/images/data-explorer/formats/html.svg) | **HTML** | A standalone page you can host |

To change a report you've already made, just ask — Resona patches the part that changed instead of rebuilding the whole document.

## 6 — Unified Agent Architecture

Chat is one of four surfaces. All of them share the same persistent memory, so anything you set here is already known to the others:

| Surface | Where to find it | Best for |
|---|---|---|
| **Chat** | This page | Precise analytical answers, data deep-dives, and written reports |
| **[Voice](/resona-ai/voice)** | Resona Voice (`Ctrl`/`Cmd` + `K` or input icon) | Hands-free verbal analysis while browsing the app |
| **[Dashboard](/resona-ai/dashboard)** | Resona Dashboard AI (`Ctrl`/`Cmd` + `J`) | Metrics, trends, cohorts, and visual KPI cards |
| **[Memory](/resona-ai/memory)** | Memory settings | Reviewing and updating what Resona has learned |
