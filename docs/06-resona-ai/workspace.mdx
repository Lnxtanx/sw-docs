# Workspace & Projects

Resona keeps what it generates. The **Workspace** holds your generated files, **Projects** group related conversations together, and **Artifact History** gives you a searchable archive of everything produced so far.

---

## Workspace

The Workspace is a persistent store for the reports and exports Resona produces. Open it from the workspace icon in the AI panel toolbar.

### What's in it

| Format | Best for |
|---|---|
| **PDF** | Printed reports, email attachments |
| **HTML** | Browser-based sharing, embedded reports |
| **CSV** | Raw result sets, further processing |
| **Excel** | Formatted workbooks |

### Managing files

Each file can be downloaded, renamed, and deleted. If Resona regenerates a report in the same session, both versions are kept.

Files are scoped to the **Project** that was active when they were created. If you aren't using Projects, everything goes into the default workspace.

---

## Projects

A Project groups related conversations and their outputs under one name — so when you're investigating something specific, everything about it stays together.

![Your Projects screen in Resona AI showing organized workspaces, Create New Project card, and active project tiles with recent activity](/images/de/resona-ai/de/project.png)

A project contains:

- The chat sessions assigned to it
- The Workspace files generated in those sessions
- The artifacts from those sessions
- A colour and icon you choose for quick recognition

Open the **Projects** panel from the sidebar, click **New Project**, and name it. Select the project before or after starting a chat to assign it, and move a chat between projects at any time from the chat options menu.

---

## Artifact History

Every table, report, and file Resona has produced — across all sessions and projects — is searchable here.

**Filter by** the text of the original question, the artefact type, a date range, or a specific project.

**From any entry you can** reopen it in its full interactive view, copy the SQL behind it, jump back to the conversation that produced it, or pin it to your dashboard.

That last one is useful when you remember an analysis from weeks ago but can't remember which chat it was in.
