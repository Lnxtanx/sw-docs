# Resona AI

Resona is Schema Weaver's AI assistant. In the **Data Explorer** it works your live database, and it comes in four forms that share the same memory. It also appears in the **SQL Editor**, where it works on your schema instead.

Same account, same credit pool across all of it.

---

## In the Data Explorer

| Form | What it's for |
|---|---|
| **[Chat](/resona-ai/ai-chat)** | Ask questions in plain English, get written reports and exports |
| **[Voice](/resona-ai/voice)** | Ask out loud instead of typing |
| **[Dashboard](/resona-ai/dashboard)** | Build an executive dashboard of KPIs, trends, cohorts and insights |
| **[Memory](/resona-ai/memory)** | What Resona carries forward between conversations |

They share one memory, so a metric definition you set in chat is already known to the dashboard and to voice.

![Resona AI open in the Data Explorer showing the natural-language chat interface, table chips, and voice launch shortcut](/images/de/resona-ai/de/de.png)

### How it works

Resona writes and runs its own SQL. One tool executes queries and the model does the analysis inside that SQL, so the approach fits your question rather than being fixed in advance. Queries are read-only, run against a single database, and are checked by the Connector before they reach it.

It plans its own work and recovers from its own mistakes — if a query fails, it works out why and changes something rather than retrying blindly.

## In the SQL Editor

Resona also works on your schema. It reads your project files, reasons over your compiled schema graph and ER diagram, makes targeted multi-file edits, and applies migrations — from a conversation.

![Resona AI open in the SQL Editor showing the agentic chat interface with tool execution and schema context](/images/sql-editor/resona-ai.png)

## Which one to use

| | Data Explorer | SQL Editor |
|---|---|---|
| **Works with** | Live database rows | Schema definitions and project files |
| **Produces** | Answers, written reports, exports | SQL DDL, file edits, migration scripts |
| **Database needed** | Yes | Only for migrations and drift |
| **Changes anything** | No — read-only | Yes — writes files, applies migrations |
| **Visual output** | Dashboards, voice | None |

Use the Data Explorer to query and understand live data. Use the SQL Editor to design and evolve the schema behind it.

---

## Shared Credits

Credits are shared across both surfaces — a conversation in the SQL Editor and a query in the Data Explorer both draw from the same monthly pool. Use Resona wherever it's most useful without managing separate budgets.

Plan details and credit costs live in [Plans and Credits](/pricing).

## Getting Started

**In the Data Explorer**

1. Open [data-explorer.schemaweaver.dev](https://data-explorer.schemaweaver.dev/)
2. Select a database connection
3. Ask a question — or press the voice orb and ask out loud

→ [Chat Interface](/resona-ai/ai-chat)

**In the SQL Editor**

1. Open [sql-editor.schemaweaver.dev](https://sql-editor.schemaweaver.dev/)
2. Open a project and click **Resona AI** in the left sidebar
3. Ask anything about your schema

→ [Resona AI in the SQL Editor](/sql-editor/ai-assistant)
