# [Schema Weaver](/introduction) — The First Voice-Native Analytics Workspace for PostgreSQL

Connect a database. Browse it in a high-performance grid, ask Resona AI in plain English, or talk to it by voice.

---

## What is Schema Weaver?

Two connected surfaces, sharing one account and one set of database connections:

- **Data Explorer** — explore live data, and talk to it.
- **SQL Editor** — design the schema behind it.

---

## The Two Product Surfaces

- **[Data Explorer](https://data-explorer.schemaweaver.dev/)** — the analytics workspace. Browse tables, filter and sort live rows, inspect column statistics, ask Resona AI in natural language, talk to your database by voice, build dashboards, and export to CSV, Excel, JSON, SQL, or Google Sheets.

- **[SQL Editor](https://sql-editor.schemaweaver.dev/)**  
  Write schema, visualize the ER diagram, analyze it with the compiler, and manage migrations against a live database.

Both surfaces share the same database connections, projects, and team memberships. You connect a database once and it is available everywhere.

---

## What You Can Do

**Data Exploration**
- Browse any table with a high-performance, filterable data grid
- Filter with typed operators, sort server-side, and hide columns you don't need
- Analyze columns — null rates, distinct counts, value distributions
- Ask Resona AI to write queries and build reports from your data
- **Talk to your database** — start a voice session and ask questions out loud
- Generate a dashboard of KPI cards, trends, cohorts, and insights from your whole database
- Export the current view, selected tables, or an entire schema

**Schema Development**
- Write PostgreSQL DDL across multiple files and folders in a structured project
- See your schema graded and analyzed across 20 quality layers in real time
- Visualize every table, view, function, and relationship as an interactive ER diagram
- Use Resona AI to generate SQL, explain schema decisions, and run surgical edits across files

**Database Sync**
- Pull the live schema from any PostgreSQL database into your project files
- Diff your project SQL against the live database before pushing
- Apply migrations safely — with advisory locking, drift detection, and automatic rollback support
- Detect when someone changed the database outside of Schema Weaver

**Team Collaboration**
- Invite teammates to projects with owner or member roles
- Share database connections without sharing credentials
- Track every file edit and migration by author and timestamp

## Quick Start

1. Open the **[Data Explorer](https://data-explorer.schemaweaver.dev/)** and connect a PostgreSQL database
2. Pick a schema and click a table — your rows load in the grid
3. Click a column header for statistics, or **Filter** to narrow rows down
4. Ask Resona AI a question in plain English, or press the voice orb and **ask it out loud**
5. **Export** the view, a selection of tables, or the whole schema

Already designing a schema? Open the **[SQL Editor](https://sql-editor.schemaweaver.dev/)**, create a project, add a `.sql` file, and watch the ER Diagram and Schema Compiler update as you type.
