# Exporting Data

Anything you can see in the Data Explorer, you can take with you. Export the exact view you're looking at, one or many tables, or every table in a schema bundled into a single ZIP — as **CSV, Google Sheets, Excel, JSON, or SQL**.

---

## Export formats

| | Format | Best for |
|---|---|---|
| ![CSV](/images/data-explorer/formats/csv.svg) | **CSV** | Spreadsheets, BI tools, scripts |
| ![Google Sheets](/images/data-explorer/formats/google-sheets.svg) | **Google&nbsp;Sheets** | Shared spreadsheets |
| ![Excel](/images/data-explorer/formats/excel.svg) | **Excel** | Formatted Excel workbooks |
| ![JSON](/images/data-explorer/formats/json.svg) | **JSON** | Apps and API payloads |
| ![SQL](/images/data-explorer/formats/sql.svg) | **SQL** | Replaying into another database |

These are the same icons you see in the export popover, so you can match a format to its icon at a glance.

---

## The three export scopes

Not sure which format? Pick what you want to take with you first — the **Export** button in the top-right of the Data Explorer lets you choose the scope before you choose the format.

| Scope | What you get | Grid state applied? |
|---|---|---|
| **View** | Exactly what you're looking at — current filters, sort order, and visible columns | Yes |
| **Table** | Full data for one or more tables you select | No |
| **Database** | Every table in one or more schemas, bundled as a ZIP archive | No |

---

### 1. View Scope — WYSIWYG Grid Export

The **View** tab exports the current grid state exactly as you have configured it on screen.

![Export View popover in Schema Weaver Data Explorer showing active view summary, row count, column dimensions, format selector, and row limits](/images/de/export/view-export.png)

- **Active View Summary**: Anchored to the active table (e.g. `public.admin_chat`) with an `Active View` badge.
- **Grid Dimensions**: Displays estimated visible rows (e.g., `~500 rows`) and column count (`12/12 columns`).
- **Preserved State**: Retains all active filter conditions, column sorting orders, and hidden column configurations.
- **Safety Limit**: Select a row cap (default `10k rows`).
- **Action**: Click **Export View (<Format>)** to download your formatted export immediately.

---

### 2. Table Scope — Targeted Table Selection

The **Table** tab allows you to export raw, unfiltered data from one or more selected tables within the active schema.

![Table Export popover showing multi-table selection checkboxes, live search filter, estimated row counts, format options, and row limits](/images/de/export/table-export.png)

- **Search & Filter**: Use the `Filter tables...` search input to quickly isolate tables in large schemas.
- **Checklist & Select All**: Select individual tables or click **Select all** to batch export multiple tables.
- **Row Estimates**: Shows live row count estimates directly next to each table (e.g. `admin_chat ~1962`, `ai_token_logs ~30984`).
- **Selection Summary**: The footer displays total selected tables and schema name (e.g., `1 table selected (admin_chat)`, `Schema: public`).
- **Unfiltered Data**: Unlike the View scope, Table exports bypass UI filters and sorts to export the canonical table data.

---

### 3. Database Scope — Multi-Schema ZIP Archive

The **Database** tab bundles all tables across your selected schemas into a single, downloadable `.zip` archive.

![Full Database Export popover showing schema checklist with table counts, format options, and Export Database as ZIP action](/images/de/export/database-full-export.png)

- **All Schemas Checklist**: Toggle **All schemas** (`63 tables`) or check individual schemas (e.g. `public (21)`, `analytics (2)`, `audit (1)`, `inventory (1)`, `staging (1)`).
- **Format Selection**: Choose between CSV, Excel, JSON, or SQL for every table in the archive.
- **Archive Structure**: Packages each table into an individual file inside the ZIP archive (e.g., `schema_export_2026-04-04.zip`).
- **Google Sheets Note**: Google Sheets is disabled for multi-schema ZIP archives because it requires creating individual cloud documents.

This distinction between scopes matters: **View** is WYSIWYG, while **Table** and **Database** exports ignore filters and sorts to export complete datasets.

## Row limits

Exports are capped so a single request can't run away on a large table.

| Preset | Rows |
|---|---|
| 1k rows | 1,000 |
| 5k rows | 5,000 |
| **10k rows** | **10,000 — default** |
| 25k rows | 25,000 |
| 50k rows | 50,000 |

The default is **10,000 rows per table**. Pick a higher preset if you need more — the limit is applied server-side, so a larger export simply takes longer.

If your export hits the cap you'll see a confirmation noting it, for example *"Capped at 10,000 rows."*

> **Database (ZIP) exports ignore the row limit.** The limit only applies to the **View** and **Table** scopes. For a full-schema export, the backend decides how much it writes per table.

## Google Sheets export

Google Sheets creates a spreadsheet directly in your Drive and hands you a link to it.

1. Select **Google Sheets** as your format.
2. Click the export button.
3. Sign in to Google when prompted and approve access.
4. Your spreadsheet opens in a new tab, and a link is also shown in the export panel.

A few things worth knowing:

- **Requested permission is `drive.file`** — Schema Weaver can only create files. It cannot read, edit, or delete anything else in your Drive.
- **Authorization is remembered** for about an hour, so you won't be prompted on every export. Expired authorization re-prompts automatically on the next attempt.
- **Sheet names** follow `schema.table (YYYY-MM-DD)`, for example `public.users (2026-04-04)`.
- **Recent Sheets exports** are listed inside the export panel, so you can jump back to a spreadsheet you created earlier without re-exporting.
- **Not available for the Database scope.** Google Sheets is disabled for ZIP exports — pick CSV, Excel, JSON, or SQL for those.

## Choosing tables and schemas

**Table scope** lists every table in the current schema. Search the list when it gets long, and use the checkbox to select several tables at once. The panel footer shows how many are selected and, for a single table, which one.

**Database scope** lets you pick which schemas to include. By default all schemas that contain tables are included; untick individual schemas to narrow it down, or untick everything except one to export a single schema.

---

## File names

| Scope | How the name is built |
|---|---|
| **View / Table** | Set by the server from the table name and format |
| **Database (ZIP)** | An archive containing one file per table — for example `schema_export_2026-04-04.zip` |
| **Google Sheets** | `schema.table (YYYY-MM-DD)` |

---

## Export states

| Situation | What happens |
|---|---|
| No connection selected | **Export** is disabled |
| No table selected | **View** is unavailable; **Database** opens by default |
| No tables selected in Table scope | Export button disabled |
| Sheets selected with Database scope | Export button disabled, with an inline note explaining why |
| Export in progress | Button shows a spinner and a progress counter; inputs are locked |
| Export cancelled | A confirmation appears |
| Export failed | An error appears and the export panel stays open so you can retry |
| Some tables in a multi-table export failed | The confirmation reports how many succeeded |

## Use cases

**Hand a result to someone else**

Export the **View** scope after filtering and sorting — the file contains exactly the question you asked, with no extra rows to trim.

**Load into a notebook**

JSON for pandas, R, or Jupyter. Point your loader at the downloaded file.

**Move data between environments**

Export as SQL and replay the statements in another database.

> **Note:** the SQL export contains `INSERT INTO` statements for the data only — it does not include table definitions. Create the schema first, then replay the inserts.

**Snapshot a whole environment**

Export every schema as a ZIP on a schedule and keep the archives as dated backups.
